# 2022版义务教育课程方案与课程标准总览

> 基于《义务教育课程方案（2022年版）》及16门学科课程标准整理
> 融入日期：2024-09-13

---

## 一、课程方案核心要点

### 培养目标
全面落实"有理想、有本领、有担当"的时代新人培养要求。

### 学制与课时
- 九年一贯设置，"六三"学制或"五四"学制
- 九年新授课总课时：**9522课时**
- 一至二年级每周26课时；三至六年级每周30课时；七至九年级每周34课时

### 课程设置变化（2022版 vs 旧版）
| 变化 | 说明 |
|------|------|
| 整合品德课程 | 小学原品德与生活、品德与社会 + 初中原思想品德 → **道德与法治**（九年一体化） |
| 改革艺术课程 | 一至七年级以音乐、美术为主线，融入舞蹈、戏剧、影视；八至九年级分项选择 |
| 科学提前 | 科学、综合实践活动起始年级提前至**一年级** |
| 独立设课 | **劳动**、**信息科技**从综合实践活动中独立出来 |
| 跨学科学习 | 各门课程用不少于 **10%** 课时设计跨学科主题学习 |

## 三、新增学科核心内容框架

### 地理（七至九年级）
**内容框架**：宇宙 → 地球 → 地表 → 世界 → 中国 → 家乡
- **认识全球**：地球运动、地图、天气与气候、陆地与海洋
- **认识区域**：世界地理、中国地理、乡土地理
- **地理工具**：地球仪、地图、遥感、GIS
- **地理实践**：野外考察、社会调查、地理实验

### 信息科技（三至八年级）
**六条逻辑主线**：数据、算法、网络、信息处理、信息安全、人工智能
- **小学低年级**：信息交流与分享、信息隐私与安全（体验为主）
- **小学中高年级**：在线学习与生活、数据与编码（基本概念+体验应用）
- **初中**：物联网实践与探索、人工智能与智慧社会（深化原理+问题解决）

### 数学（一至九年级）
**四大领域**：数与代数、图形与几何、统计与概率、综合与实践
- **核心素养"三会"**：会用数学的眼光观察现实世界、会用数学的思维思考现实世界、会用数学的语言表达现实世界
- **跨学科**：每学期不少于10%课时用于跨学科主题学习

### 艺术（一至九年级）
**五个学科**：音乐、美术、舞蹈、戏剧（含戏曲）、影视（含数字媒体艺术）
- **一至二年级**：唱游·音乐、造型·美术
- **三至七年级**：以音乐、美术为主，融入舞蹈、戏剧、影视
- **八至九年级**：分项选择，至少选2项

### 劳动（一至九年级）
**三类劳动**：日常生活劳动、生产劳动、服务性劳动
- **十个任务群**：清洁与卫生、整理与收纳、烹饪与营养、家用器具使用与维护、农业生产劳动、传统工艺制作、工业生产劳动、新技术体验与应用、现代服务业劳动、公益劳动与志愿服务

## 四、跨学科主题学习要求

2022版课程方案的突出亮点：**每门课程不少于10%课时用于跨学科主题学习**。

### 与科学教育相关的跨学科主题示例

| 主题 | 涉及学科 | 核心问题 |
|------|----------|----------|
| 碳中和与绿色生活 | 科学+地理+化学+道德与法治 | 如何减少碳排放？ |
| 智能农业 | 信息科技+生物+数学+劳动 | 如何用技术优化农业生产？ |
| 声音的艺术与科学 | 物理+艺术+数学 | 声音如何产生美妙音乐？ |
| 城市规划师 | 数学+地理+艺术+信息科技 | 如何设计可持续发展的城市？ |
| 人体健康数据 | 生物+数学+信息科技+体育 | 如何用数据管理健康？ |
